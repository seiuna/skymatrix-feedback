# SkyMatrix 问题反馈

这里用于收集 SkyMatrix 的 Bug、功能建议和使用问题。

## 提交反馈

- [报告 Bug](https://github.com/seiuna/skymatrix-feedback/issues/new?template=bug_report.yml)
- [提出功能建议](https://github.com/seiuna/skymatrix-feedback/issues/new?template=feature_request.yml)
- [查看已有反馈](https://github.com/seiuna/skymatrix-feedback/issues)

提交前请先搜索已有 Issues。同一问题已有反馈时，可以在原帖补充复现信息，避免重复提交。

报告 Bug 时，请写明 SkyMatrix 版本、Minecraft 版本、运行环境、复现步骤和实际表现。截图、报错信息或日志有助于定位问题；粘贴前请删去账号令牌、密码、服务器地址等私人信息。

本仓库仅用于公开反馈，不包含 SkyMatrix 源代码。反馈内容和附件会公开显示，请勿上传私有代码或敏感数据。
